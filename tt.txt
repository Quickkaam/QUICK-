## 🎯 Executive Summary

**Drishti Kavach** is a fully professional Security Operations Center (SOC) Dashboard that:

- Monitors website activity, detects threats, manages IP addresses, reviews form submissions
- **Detects and mitigates DDoS attacks** automatically (traffic spikes, IP floods, botnets, geo‑spikes)
- **Supports multiple websites** – monitor your own sites AND client sites from a single dashboard
- **AI‑powered auto‑setup** – add a new website by uploading its files; AI injects tracking code automatically
- **AI Virtual Assistant (Drishti AI)** works autonomously in your absence (auto‑investigate, auto‑block, chat)

**Goal:** Run indefinitely with **zero recurring cost** by leveraging generous free tiers, open‑source technologies, and smart resource management.

## 🧠 Core Principles for Long‑Term Success

| Principle | Implementation |
|-----------|----------------|
| **Vendor Independence** | Use standard SQL, REST APIs, and static frontends – easy to migrate |
| **Data Ownership** | All data in your own PostgreSQL instance (Supabase) |
| **Resource Efficiency** | Cache IP intelligence, batch writes, avoid unnecessary API calls |
| **Data Retention** | Auto‑archive/delete old logs to stay within free DB limits |
| **Scalability** | Free tiers sufficient for small‑to‑medium traffic; upgrade path clear |
| **Open Source** | Use MIT/Apache licensed libraries – no licensing costs |
| **AI Integration** | DeepSeek API (free) for autonomous threat handling |
| **Multi‑Tenant Design** | One dashboard, many websites – isolated client data |
| **Zero‑Touch Onboarding** | AI‑powered file injection – no manual code changes needed |

## 🛡️ DDoS Attack Detection & Protection

### Detection Methods (All Automated)

| Detection Type | Threshold | How It Detects | Severity |
|----------------|-----------|----------------|----------|
| **Traffic Spike** | > 3x average (60‑min) | Compares last 5 min vs last 60 min average | Warning |
| **Critical Traffic Spike** | > 10x average (60‑min) | Compares last 5 min vs last 60 min average | Critical |
| **IP Flood** | > 100 requests/min from single IP | Counts requests per IP in 1‑minute window | Warning |
| **Severe IP Flood** | > 500 requests/min from single IP | Counts requests per IP in 1‑minute window | Critical |
| **Botnet (UA Flood)** | Single UA > 50% of total traffic | Counts User‑Agent distribution | Warning |
| **Geographic Spike** | Single country > 70% of total traffic | Uses IP geolocation to track country distribution | Warning |
| **Slowloris Detection** | Response time > 5s for > 10 requests | Measures API response time | Warning |

### Mitigation Actions (Auto‑Executed)

| Detection | Action 1 | Action 2 | Action 3 |
|-----------|----------|----------|----------|
| **Traffic Spike (Warning)** | 🔔 Alert (Slack + Telegram) | Create DDoS incident | Monitor for escalation |
| **Traffic Spike (Critical)** | 🔔 Critical Alert | **Enable Cloudflare Under Attack Mode** | Block top 10 offending IPs |
| **IP Flood** | Auto‑block the IP for 24h | Alert | Add to incident |
| **Botnet (UA Flood)** | Rate‑limit the UA at API level | Alert | Add to incident |
| **Geographic Spike** | Block the entire country temporarily | Alert | Add to incident |
| **Slowloris** | Increase rate‑limiting timeout | Alert | Add to incident |

-- DDoS Events
CREATE TABLE ddos_events (
  id BIGSERIAL PRIMARY KEY,
  website_id BIGINT REFERENCES websites(id),
  severity VARCHAR(20), -- warning, critical
  attack_type VARCHAR(50), -- traffic_spike, ip_flood, botnet, geo_spike, slowloris
  details JSONB,
  affected_ip INET,
  total_requests INTEGER,
  avg_requests INTEGER,
  mitigation_taken BOOLEAN DEFAULT FALSE,
  mitigation_details JSONB,
  status VARCHAR(20) DEFAULT 'active',
  created_at TIMESTAMP DEFAULT NOW(),
  resolved_at TIMESTAMP
);
CREATE INDEX idx_ddos_website_id ON ddos_events(website_id);
CREATE INDEX idx_ddos_created ON ddos_events(created_at);

CREATE TABLE ddos_mitigations (
  id BIGSERIAL PRIMARY KEY,

  action VARCHAR(50), -- cloudflare_under_attack, ip_block, geo_block, rate_limit
  target VARCHAR(255),
  status VARCHAR(20), -- success, failed
  details JSONB,
  created_at TIMESTAMP DEFAULT NOW()
);

  severity VARCHAR(20),

  created_at TIMESTAMP DEFAULT NOW()
);
